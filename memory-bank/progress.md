# Progress: Inukings UIKit

## What Works

### Core Components

The library has a comprehensive set of functioning core components:

- **Alert**: Notification component with different variants
- **Breadcrumbs**: Navigation breadcrumb component
- **Button**: Standard and icon buttons
- **ButtonMenu**: Menu component built from buttons
- **Card**: Card component with header, body, footer, and ribbon variations
- **Checkbox**: Form checkbox component
- **Dropdown**: Dropdown selection component
- **Flex**: Layout component for flexbox arrangements
- **Heading**: Typography component for headings
- **Image**: Image component with various display options
- **Input**: Form input component
- **Layouts**: Base layout components
- **Link**: Standard and external link components
- **Overlay**: Overlay component for modals and other floating elements
- **Progress**: Progress indicator component
- **Radio**: Form radio button component
- **Skeleton**: Loading skeleton component
- **Spinner**: Loading spinner component
- **Svg**: SVG icon component system
- **Table**: Data table component
- **Tag**: Tag/label component
- **Text**: Typography component for text
- **Toggle**: Toggle switch component

### Widgets

Higher-level composed components:

- **Menu**: Navigation menu system
- **Modal**: Modal dialog system
- **Toast**: Toast notification system
- **WalletModal**: Specialized modal for wallet connections

### Theming System

- Light and dark themes
- Theme provider integration
- Responsive design support via theme breakpoints

### Development Infrastructure

- Storybook documentation
- Jest testing framework
- TypeScript type definitions
- Build pipeline with Rollup
